# DeskStream — versões

Os instaladores do [DeskStream](https://deskstream.site): acesso ao PC pelo
celular, segunda tela, câmera e microfone do celular no PC e ajuda por código.

Baixe sempre pelo site — https://deskstream.site/baixar —, que aponta para a
versão mais recente daqui. Este repositório guarda só os instaladores; o
código não é público.
